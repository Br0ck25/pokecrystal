Working rules
Think before coding. Don't assume; state assumptions; if unsure, ask; if several interpretations exist, present them; push back on complexity.

Simplicity first. Minimum code that solves the problem; nothing speculative; no single-use abstractions.

Surgical changes. Touch only what you must; match existing style; every changed line traces to the request. When new code replaces old, delete the old code, art, data and tests in the same change.

Goal-driven. Turn tasks into verifiable goals (bug -> reproduce then fix; feature -> test). Loop until verified.

Build every scene from Crystal's own data, never from memory or guesses.
